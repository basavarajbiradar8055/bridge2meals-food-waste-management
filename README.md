# Bridge2Meals – Ensuring No One Goes Hungry

## Overview
Bridge2Meals is a Food Waste Management System developed as a **Societal Project** during III Semester MCA at New Horizon College of Engineering, Bengaluru. The system connects food donors with NGOs and delivery agents to reduce food wastage and ensure surplus food reaches those in need.

## My Contribution
I worked as a **Frontend Developer** — designed and built the user interface for all three modules (User, Admin, Delivery) using HTML, CSS and JavaScript. I also integrated the database and tested the complete system.

## Features
- User registration and food donation form
- Admin dashboard to manage donations and users
- Delivery agent module with map-based tracking
- Chatbot support with speech recognition
- Secure login for all three modules
- Mobile responsive design

## Modules
- **User Module** — Register, login and donate food
- **Admin Module** — Manage donations, users and delivery agents
- **Delivery Module** — View assigned pickups and update delivery status
- **Chatbot Module** — Automated help with speech support

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** XAMPP
- **Version Control:** Git & GitHub

## Database Tables
- user
- food_donation
- admin
- delivery_person
- user_feedback

## Getting Started
1. Install XAMPP
2. Copy project folder to `C:\xampp\htdocs\Bridge2`
3. Open phpMyAdmin → Create database `socitaldb`
4. Import `database/demo.sql`
5. Open browser → `http://localhost/Bridge2`
